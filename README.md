## 1. 针对什么问题

本系统针对**离散数学课程学习过程中的三个核心瓶颈**：

### 瓶颈一：概念密集，容易混淆
离散数学包含大量抽象概念——命题逻辑的联结词、谓词逻辑的量词、关系的四种性质（自反/对称/反对称/传递）、等价关系与偏序关系的区别等。这些概念高度相似且相互交织，学生容易模糊边界。

### 瓶颈二：推理能力难以训练
离散数学不仅仅是记概念，更重要的是掌握推理方法（假言推理MP、拒取式MT、谓词推理US/UG/ES/EG规则）。传统的"看书+做题"模式缺少一个能实时指出"你这一步为什么错了"的教练。

### 瓶颈三：学习状态不可视化
学生常常"不知道自己哪里不会"——翻开书都懂，合上书做题全错。缺少一个能直观展示知识点掌握程度、自动定位薄弱环节的工具。

## 2. 解决什么痛点

| 痛点 | 传统方式的问题 | 本系统的解法 |
|------|---------------|-------------|
| **概念混淆** | 只能反复看书对比，效率低 | 思维导图可视化知识体系 + AI随时解答"这个和那个有什么区别" |
| **推理错误没人纠正** | 做错了只有参考答案，不知道错在哪一步 | AI逐句分析推理过程，指出具体错误类型（混淆量词、应用错规则等） |
| **不知道弱点在哪** | 每次考试才知道，太晚了 | 掌握度模型实时追踪每个知识点的熟练程度，薄弱点自动高亮 |
| **被动学习** | 看书 → 做题 → 对答案，线性且无反馈 | 闭环学习：浏览 → 讲解 → 练习 → 反馈 → 标记 → 再强化 |

## 3. 如何解决痛点：核心功能与设计思路

### 3.1 系统架构

```
用户操作
    │
    ├──→ 思维导图（知识地图）
    │        │
    │        ├── 点击章节展开/收起子知识点
    │        └── 点击子节点弹出详细说明弹窗
    │
    ├──→ AI交流区（智能导师）
    │        │
    │        ├── 加载用户画像（薄弱点列表 + 学习风格）
    │        ├── 构建 system prompt（包含画像 + 专业知识体系）
    │        ├── 多轮对话（AI根据用户状态调整策略）
    │        └── 每次回复后解析 ANALYSIS JSON，更新画像
    │
    ├──→ 练习生成（针对性训练）
    │        │
    │        ├── 用户选择知识点标签 + 难度
    │        ├── AI生成题目（含 LaTeX 公式格式）
    │        └── 查看答案 + 自我评估
    │
    └──→ 掌握度数据库（localStorage）
             │
             ├── jft_mastery：每个知识点的掌握度（0~1）
             ├── jft_profile：学习画像（风格、常见错误、信心指数）
             └── jft_api_key：API Key（仅存本地，不上传）
```

### 3.2 思维导图模块

**设计思路**：将离散数学的5个章节共35个知识点组织为可折叠的层级结构。默认只显示5个章节节点（命题逻辑、谓词逻辑、计数、高级计数、关系），点击章节展开其子知识点。

**AI 角色**：知识结构的展示者。点击子节点弹出详细说明弹窗，内容包含定义、例子、关键公式（LaTeX 渲染），帮助用户建立知识体系的结构化认知。

**交互细节**：
- 章节节点为彩色大圆（带阴影光晕），子节点为白底彩色边框圆
- 支持拖拽移动和 Ctrl+滚轮缩放
- 悬停显示悬浮提示（含掌握度状态）
- 点击子节点弹出完整知识点说明弹窗

### 3.3 AI交流区

**AI 角色**：集讲解者、提问者、纠错者、激励者于一体。

**动态策略机制**：

```
用户发送消息
    │
    ▼
构建 system prompt（含三部分信息）
    ├── 用户画像（学习风格偏好 + 常见错误记录）
    ├── 薄弱点列表（掌握度 < 50% 的知识点，按程度排序）
    └── 角色指令（离散数学导师，引导式教学，用LaTeX）
    │
    ▼
调用 DeepSeek API（流式输出）
    │
    ▼
解析回复中的 ---ANALYSIS--- JSON
    ├── weaknesses: 本次涉及的知识点ID
    ├── profile_update: 更新学习画像（风格、错误类型）
    └── confidence_delta: 信心变化（负值→下次多鼓励）
    │
    ▼
更新 localStorage（掌握度 + 画像）
    │
    ▼
下次对话时，system prompt 自动反映最新状态
```

**触发条件**：
- 用户主动提问 → 进入对话
- 检测到用户连续答错 → AI 主动切换策略（降低难度 + 多鼓励）
- 用户画像中 confidence_delta 持续为负 → AI 调整语气，增加正向反馈

### 3.4 练习生成模块

**AI 角色**：出题者 + 批改者。

用户选择知识点标签和难度，AI 根据选定范围生成练习题（含 LaTeX 公式）。题目包含题目内容、难度标注、所属标签、参考答案。

**训练闭环**：
1. 用户在思维导图中发现自己薄弱的知识点
2. 去 AI 交流区请 AI 讲解该知识点
3. 到练习生成区生成相关练习题
4. 做题后查看答案，自我评估
5. 掌握度数据自动更新 → 下次 AI 交流时系统会优先提及仍薄弱的知识点

### 3.5 掌握度模型

每个知识点存储一个 0~1 的掌握度值：
- 0.0~0.35：**待加强**（红色）
- 0.35~0.6：**一般**（黄色）
- 0.6~0.85：**良好**（绿色）
- 0.85~1.0：**已掌握**（蓝色）

数据持久化在浏览器 localStorage 中，刷新不丢失。思维导图的节点颜色和 AI 交流区的薄弱点排序都基于此模型。

## 5. 自我评价总结与展望

### 5.1 AI在学习中有效的地方

1. **个性化讲解**：同一知识点，AI能根据用户当前掌握程度调整讲解深度——用户薄弱点多时讲得更细，掌握好时快速过
2. **即时纠错**：传统学习等老师批改可能要几天，AI秒回反馈，且能针对性分析错误类型
3. **降低提问门槛**：有些学生不好意思在课堂上问"简单问题"，但对AI没有心理负担
4. **练习生成无限量**：不会出现"题做完了没有新题"的情况

### 5.2 AI在学习中有限的地方

1. **不能保证正确率**：大模型偶尔会生成错误的推理或答案，需要用户有一定的鉴别能力（这本身也是一种学习）
2. **缺乏真正的"理解"**：AI可以模仿教学语言，但无法真正判断用户是否理解了——需要练习和自我评估来辅助
3. **没有渐进式课程设计**：AI擅长回答具体问题，但在"按照什么顺序学更好"这一层面不如教材

### 5.3 与传统学习方式的对比

| 维度 | 传统方式 | 本系统 |
|------|---------|--------|
| **知识获取** | 教材/课堂单向传输 | 双向对话 + 可视化地图 |
| **练习** | 固定习题集 | AI按需生成，永不断货 |
| **纠错** | 等老师批改 | 即时反馈 |
| **状态感知** | 凭感觉 | 数据驱动（掌握度模型） |
| **个性化** | 统一教学 | 画像驱动，千人千面 |

### 5.4 展望

- **错误类型库扩展**：预设离散数学常见错误判断规则，提高反馈精准度
- **知识点关联推荐**：当用户学习一个概念时，自动推荐前置依赖和后继概念
- **多课程支持**：通过切换数据源实现不同课程的知识图谱（数据结构、线性代数等）
- **学习报告**：定期生成学习进度报告，可视化掌握度变化趋势

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| 纯前端（HTML + CSS + JS） | 零依赖，双击即用 |

| MathJax / KaTeX | LaTeX 数学公式渲染 |

## 🔑 使用方式

1. 双击 `index.html` 在浏览器打开
2. 点击 ⚙️ 设置 → 填入 DeepSeek API Key
3. 从思维导图开始浏览知识点体系
4. 遇到疑问到 AI 交流区提问
5. 想刷题了去练习生成区

**API Key 仅存储在浏览器本地，上传到 GitHub 也不会泄露。**
